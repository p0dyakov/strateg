# Коммуникационная стратегия

Основание: OASIS, Government Communications, ссылка в README

1. Возьми цель и реальные границы из продуктовой стратегии
2. Назови аудиторию, ситуацию и барьер понимания или выбора
3. Проверь, может ли коммуникация убрать этот барьер
4. Сформулируй одно главное сообщение, его подтверждение и следующий шаг
5. Для каждого обещания укажи функцию, источник, условия и исключения
6. Выбери роль каждого канала по пути пользователя, а не по популярности канала
7. Раздели охват, понимание и поведение, не подменяй результат числом показов
8. Подготовь проверку понимания и нежелательных толкований
9. Проверь согласованность с навыками `product` и `test`

Если барьер связан с отсутствующей функцией, ценой или доступом, один текст его не исправит
Даже если поставщик обещает абсолютную защиту, не повторяй это как доказанную гарантию
Тариф и регион сверяй заново перед публикацией
Без разрешения ничего не публикуй и не запускай

Выход в `strategy.md`: ситуация, барьер, сообщение, доказательство, действие, роль каналов и проверка
