# Разбор опыта

Основание: GOV.UK discovery и открытая UX-лаборатория МегаФона в README

1. Укажи задачу пользователя и доступный фрагмент пути
2. Зарегистрируй снимок, URL или видео как источник с датой и версией
3. Для каждого наблюдения дай номер экрана, область или таймкод
4. Отдели видимое от предположения о поведении пользователя
5. Проверь порядок внимания, понятность сообщения, следующий шаг, цену, ошибки и выход
6. Укажи барьер, последствие, возможное объяснение и проверку с реальным пользователем
7. Свяжи изменение интерфейса с продуктовым выбором и обещанием в сообщении

Не заявляй о невидимых экранах, доступности по WCAG, скорости и конверсии по одному снимку
Для изображения используй зрение хоста, если оно доступно
Для аудио или видео запроси разрешённую расшифровку с таймкодами и отметь непроверенные места
Если формат не поддержан, назови границу и попроси экспорт, а не имитируй просмотр

Выход: наблюдение, локатор, гипотеза о барьере, риск, проверка
