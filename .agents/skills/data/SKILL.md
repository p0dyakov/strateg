# Анализ данных

Прочитай раздел «Измерение» в `knowledge/method.md`

1. Уточни единицу наблюдения, событие, знаменатель, окно, часовой пояс и период выгрузки
2. Проверь пропуски, дубли, единицы, полноту наблюдения и изменение схемы событий
3. Используй `python3 scripts/read.py ФАЙЛ` для просмотра структуры
4. Для подготовленных агрегатов используй `python3 scripts/data.py rates ФАЙЛ --base КОГОРТА`
5. Сохрани команду, вывод и хеш исходника, не переписывай результат по памяти
6. Сравни общий показатель и показатели внутри сегментов
7. Не делай причинный вывод из сравнения периодов
8. Перед эффектами A/B проверь SRM через `data.py srm`, явно передай согласованный порог

Формат `rates`: `cohort,segment,eligible,retained,window_days,observed_days`
Это агрегаты одного заранее определённого показателя
`observed_days` является заявлением автора выгрузки, скрипт не проверяет его по событиям
Неполная строка исключается явно, а не превращается в нулевое удержание
Стандартизация использует доли сегментов выбранной базовой когорты

Выход: воспроизводимый расчёт, проверенные ограничения и список следующих проверок
Для LTV, причинного анализа и мощности эксперимента сначала согласуй модель, данные и допущения
Не подставляй универсальные коэффициенты
